## 📖 Cara Penggunaan Cepat (1-Klik)

1. **Buka di Google Colab:**
   Klik tombol badge **"Open in Colab"** di atas atau klik tombol **"Buka Google Colab"** langsung dari panel Blender Addon Anda.
2. **Jalankan Worker:**
   Pada menu Google Colab, klik **Runtime** > **Run all** (atau tekan `Ctrl + F9`).
3. **Sambungkan Google Drive:**
   Saat muncul konfirmasi izin Google Drive, klik **Connect to Google Drive** (agar hasil video 4K otomatis tersimpan ke Google Drive Anda dalam hitungan detik tanpa perlu download lambat).
4. **Hubungkan ke Blender:**
   Klik tombol **[📋 SALIN URL]** pada Colab, lalu di Blender klik tombol **[🔗 Sambungkan dari Clipboard]**.
5. **Render Selesai:**
   Klik **Render di Colab GPU** di Blender. Nikmati kecepatan render GPU NVIDIA T4 Cloud gratis dari Google!
